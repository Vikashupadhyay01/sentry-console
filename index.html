How Sentry Console Works

A 4-step automated pipeline designed for zero-install, privacy-first security triage.

1️⃣
Upload / Select Target

Drop network captures (.pcap/.pcapng), PDFs, EML emails, Images, Office docs, or type a website domain URL.

2️⃣
Parse Locally

Binary headers, MIME streams, EXIF metadata, and OpenXML archives are parsed inside your browser memory.

3️⃣
Heuristic Threat Match

Our heuristic detection engine evaluates SYN bursts, port scans, embedded scripts, spoofed senders, and stego markers.

4️⃣
Review & Export Report

Get an instant Universal Security Score (0–100), extract IOCs, review interactive flow charts, and download PDF reports.
